# Ҳисобкунаки арзиши лоиҳа

Ҳисобкунаки мустақили нарху муҳлати тахминии сохтани сомона. Барои кор ягон китобхона ё сервер лозим нест.

## Иҷро

Файли `index.html`-ро дар браузер кушоед.

## Нашр дар GitHub Pages

1. Дар GitHub repository-и нав созед.
2. Файлҳои ҳамин папка (`index.html`, `style.css`, `script.js`, `README.md`)-ро ба решаи repository илова кунед.
3. Дар **Settings → Pages** манбаи **Deploy from a branch**-ро интихоб карда, branch-и асосӣ ва папкаи `/(root)`-ро таъин кунед.
4. Пас аз анҷоми deploy сомона бо суроғаи GitHub Pages дастрас мешавад.

## Имкониятҳо

- Интихоби навъи лоиҳа
- Ҳисоб кардани нарх вобаста ба шумораи саҳифаҳо
- Илова кардани пардохти онлайн, аниматсия ва SEO
- Намоиши диапазони нарх ва муҳлати тахминӣ
- Тарҳи мутобиқ ба телефон ва компютер
